## 📊 Dataset Source

Due to file size limitations and data redistribution policies, the raw dataset is not included in this repository. 

You can download the original dataset directly from Kaggle using the link below:
* **Dataset Name:** FMCG Sales & Profit Dataset (2023–2025)
* **Author / Owner:** Atharva Soundankar
* **License:** This dataset is designed for analysts, students, and portfolio builders
* **Direct Link:** https://www.kaggle.com/datasets/atharvasoundankar/fmcg-sales-marketing-and-profit-data

### How to Run the Project
1. Download the dataset from the Kaggle link above.
2. Create a folder named `data/` in the root directory of this project.
3. Place the downloaded `.csv` file(s) inside the `data/` folder before running the notebook or scripts.
